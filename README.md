# Minimal To-Do — V1.3

Mobile-first To-Do app optimized for an iPhone 13-sized viewport.

## V1.3
- Dark mode with persistent preference
- Working menu and settings
- Swipe-left delete
- Today / Tasks / Calendar navigation
- All / Active / Completed task filters
- Search
- Calendar month navigation
- LocalStorage persistence
- Cache-busting query versions on CSS and JS

## Update
Replace the existing `index.html`, `style.css`, `app.js`, and `README.md` in the GitHub repository.

Keep the existing localStorage key `minimal-todo-tasks-v1` so existing tasks are preserved.

## Run
Open `index.html`, or use:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
